# Bayonetta 2 Multiworld Setup

1. Build B2recomp from your own Bayonetta 2 (Switch, v1.2) dump and install the Archipelago mod (`mods\Archipelago`).
2. Start the game, choose **ARCHIPELAGO** on the main menu, set ADDRESS, SLOT and PASSWORD, then **CONNECT**.
3. Choose STORY and play: checks are sent and items arrive while you play.
